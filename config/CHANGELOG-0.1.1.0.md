# 0.1.1.0 修改与发布备注

记录日期：2026-10-16。包含本轮游戏工程、资源和发布工具改动，保留当前美术、场景与差异点调整。

## 关卡与资源

- 大关卡顺序为网络热点、2026热梗、北京至西安，共 10 个大关卡、180 个小关卡。
- 2026热梗对应 city-01-2026Hotmeme，源素材 31–60 按序映射到项目 level-01–level-30，替换两张找茬图、差异点配置并生成小图标；保留已确认名称。
- 原北京至西安顺延为 city-02 至 city-09，同步配置、资源路径、Bundle 名称、美食图鉴 JSON 和 Excel。移动已有资源保留 UUID。
- v3 存档自动迁移旧城市通关、解锁和评价；v2 数字存档映射排除两个前置专题，避免错位。
- 主页动画独立远程加载，场景用独立静态首帧，选关页提前准备动画资源。
- 收藏与排行榜拆为 SecondaryUI 按需加载，关闭及翻页时释放动态封面；详见 README-secondary-ui.md。
- 调整 HUD 刷新、页面图片和封面引用的持有/释放，保留当前场景、美术、连击音效及差异点修改。

## 交互、广告和进关

- 动态结算预制体在展示时绑定入口有奖、添加桌面、订阅入口，重复展示去重。
- 插屏加载阶段不锁住正常玩法；道具激励请求取消待展示插屏，原生关闭回调缺失后通过有效游戏按钮触摸恢复状态。
- 按钮以原设计节点 UITransform 命中范围校验，排除子节点溢出、框外释放、隐藏和禁用状态；没有重设设计尺寸。
- 卡关/低时间引导复用普通提示、加时入口；库存耗尽时请求激励视频，完成后才生效，取消或失败不直接赠送效果。H5 保持无广告辅助流程。
- 两张找茬图加载并绑定后才启用玩法页，重新置顶 Loading，首帧绘制完成才撤下遮罩和开始计时；无效纹理或缺少图片节点按失败处理。

## H5 同地址更新

- Web 手机端开启 MD5 Cache，入口按构建标识探测更新；保留 Cocos 对启动资源的哈希路径改写，修复追加查询参数导致的启动文件 404。
- 修复 Cocos 全局 div 样式覆盖 hidden 导致更新提示层始终挡住游戏的问题。
- 新增 `npm run web:package`：固定入口与 release.json 选择 releases/<内容摘要>/ 独立完整构建；不同发布不覆盖同一路径资源，保留老目录服务在线旧页面。
- 打包检查入口引用、settings、Bundle config 哈希和资源完整性。产物位于 output/web-mobile-release，不纳入 Git。
- 线上实测普通入口仍命中 30 天 CDN 旧缓存，旧逻辑请求 config.json 返回 404；绕过入口缓存后，新构建可进入玩法页，主页角色动画正常。

### 发布要求

1. 重新构建目标平台；H5 构建后执行 `npm run web:package`。
2. 上传发布目录内文件，先完整 releases/<摘要>/，最后更新 release.json；首次接入还需替换固定 index.html。
3. OSS/CDN 给固定 index.html 和 release.json 设置 `Cache-Control: no-store, max-age=0`，首次刷新原访问 URL 和入口/清单缓存。前端无法替服务器清除发布前已缓存的旧 HTML。
4. 保留旧 releases 及旧包仍引用的哈希文件。不要清空玩家 localStorage。
5. 抖音须部署同次构建的全部配套远程 Bundle，包括 SecondaryUI、MainGameAimation、MainGameSources 和城市包。
