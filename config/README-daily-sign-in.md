# 七日签到与独立弹窗（2026-11-02）

## 在 Creator 中编辑

- 弹窗：`assets/LobbySources/prefabs/DailySignInModal.prefab`。在资源管理器双击进入预制体编辑。
- 主页入口：`assets/LobbySources/prefabs/LobbyScreen.prefab` 内的 `Active/SevenDay`，已绑定到 LobbyScreen 的 `btnDailySignIn`。代码复用设计好的按钮并保留名称、位置和样式，不再自动生成或预加载额外入口。未绑定时优先按 `SevenDay` 查找，也兼容旧入口名称；找不到则跳过。
- 奖励表：`assets/resources/configs/daily-sign-in.json`，弹窗组件的 `rewardConfig` 字段也已绑定该资产。

弹窗不是运行时临时绘制的界面，所有格子、文字、图片和按钮都保存在 prefab，修改后可以直接构建生效。`tools/create-daily-sign-in-prefab.cjs` 只是一次性生成工具，不覆盖已有预制体，也不参与构建流程。

节点约定：

- `ResultDimmer`：全屏遮罩；根节点有 `BlockInputEvents`，点击不穿透主页。
- `ResultCard`：整个弹窗主体，可以编辑其尺寸、位置和美术。
- `ResultCard/Title`、`Subtitle`、`Rules`：标题、动态签到状态和规则说明。
- `ResultCard/Days/Day1` 至 `Day7`：七个独立奖励格；每格的 `DayTitle`、`Icon`、`Reward`、`State`、`Current`、`Claimed` 分别对应日期、图标、奖励文案、领取状态、当前格高亮、领取勾选。
- `ResultCard/BtnNormal`、`BtnDouble`、`BtnClose`：普通领取、视频双倍领取、关闭，组件已绑定。改名或替换时同步调整绑定和命名查找。

逻辑只更新领取状态、文字、勾选/高亮和按钮可用状态，不覆盖格子位置、图片、字体或色彩。弹窗不参与自动适配，根节点与 `ResultCard` 均按预制体设置的尺寸、位置、缩放和 Widget 显示。

项目的750×1334设计画布由 Creator 同时适配宽、高并整体等比显示；这属于项目分辨率策略，不对签到弹窗添加单独缩放。只固定宽度时，矮浏览器窗口会裁掉固定1080高的弹窗上下边界。

参照用户截图奖励数量；爱心按用户确认映射为体力。每天按北京时间零点换日，每日仅可领取一次，普通和双倍互斥。漏签一天则下一次从第1天开始，连续领满7天后从新一轮第1天开始。

每天首次进入主页时提示领取；关闭未领取后，可以通过主页入口再次打开，当天重新启动不反复自动弹出。主页跨日或回到前台时也会检查，不在对局中强行弹出。启动直接进游戏，不弹签到；玩家未返回主页时不会弹出。

双倍使用 `daily-sign-in` 激励位，复用已配置的平台激励广告单元。取消或播放失败不发奖励；看视频跨过零点不会用旧奖励领取新一天。重复点击受弹窗和全局广告并发保护。H5 继续沿用现有免广告调试行为。

奖励和签到记录一次性保存，失败整体回滚，不扣领取资格。体力可超过自然恢复上限15，存储上限仍为99；储存已满时不消耗当天资格，可消耗体力后再领。接近99时按存储上限截断。只读和奖励逻辑使用本地日期，与现有存档一样不具备服务端防改时能力。

存档新增 `dailySignIn` 字段，不改已有通关、解锁、体力和库存记录。主页入口及弹窗位于远程 LobbySources，在游戏页下后台准备；只在主页激活。提示图标使用新的公共资产 UUID，原玩法图标保留。
