# 成功通关奖励1点体力

排查时旧逻辑只有开局扣1点，成功结算没有返还体力。现调整为每个真实对局成功通关后奖励1点，方便持续闯关。

- 开局仍扣1点；成功通关后+1，失败不奖励。重玩、最后一关通关与复活后通关也按成功局奖励。
- GameFlow.finishLevel在结算入口标记本局结束，重复调用不重复保存或奖励；Feed预览不结算。
- SaveService.completeLevel新增可选rewardEnergy参数，GameFlow的胜利分支传true；默认false，避免历史通关补记、迁移或测试构造记录凭空增加体力。
- 通关进度、最优星级/时间、唯一通关积分及体力一次性保存。保存失败恢复之前的整份状态，不提交未保存的排行榜分数，并显示保存失败提示。
- 奖励遵守99点存储上限；不足15点时保留自然恢复剩余计时，达到15点时重置时间锚点并停止倒计时。已有跨页EnergyDisplay继续按账户实际数值刷新。

验证：新增test-level-clear-energy覆盖只剩1点时开局扣至0再通关恢复至1、后续继续、重玩、重复结算、失败/复活/Feed预览、99上限、15自然恢复阈值、存档失败回滚及分数提交；体力导航、体力存档、结算详情、立即插屏、留存、收藏、专题层级、复活奖励相关测试及TypeScript检查通过。

本次仅实现体力奖励，没有开启Feed后台能力或修改Feed开关，也未重新构建或真机验收。
