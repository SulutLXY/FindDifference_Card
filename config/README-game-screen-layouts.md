## 运行时适配规则

已接入按实际游戏窗口比例选择玩法预设：读取 Cocos `screen.windowSize`，网页对应游戏画布/预览容器，不读取手机物理显示屏，也不使用编辑器固定的设计分辨率判断机型。

- 最低完整布局为 750×1334（约 9:16）。更短或横向窗口继续使用这一布局，通过 SHOW_ALL 等比完整显示，剩余区域留边。
- 窗口高度/宽度小于 2 时使用 `GameScreen_9x16`，包括 9:16 与 9:18 之间的机型。
- 高度/宽度达到 2（9:18，含 0.001 取整容差）时使用 `GameScreen`。当前美术长屏预设为 750×1650，较短的长屏窗口会整体等比缩小以保证完整显示。
- 更长窗口以 750 为设计宽度，按实际比例增加设计高度。窗口调整期间只缩放当前玩法根节点，保留计时、生命和差异点进度；下一次进入关卡时重新选择预设。
- 只缩放玩法预设整体，不改内部节点布局和图片宽高比，结算等弹窗仍独立使用原设计。

体力保留原 X/Z 和外观；默认 Y 在每帧后期跟随本页 `BtnBack` 或大厅 `Setting` 的实际高度，没有对应按钮时按页顶 57 单位的距离定位。
