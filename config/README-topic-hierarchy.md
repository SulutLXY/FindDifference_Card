## 导航与资格

- 顶层点击恋爱美食后，原章节列表页展示8张城市卡片，标题变为恋爱美食；返回键回到顶层列表，再返回才回主页。
- 城市关卡页返回其所属专题的城市列表。其他独立专题返回顶层。
- 未解锁城市展示视频解锁按钮和提示，封面置灰；点击卡片或按钮请求 `unlock-city` 激励位，复用既有平台广告单元。
- 奖励只有完整观看后保存成功才生效。取消、播放错误或保存失败均不进入城市；重复点击不会并发播放广告。玩家离开当前页面后到达的广告奖励可以保留，但不自动跳转。
- 进入已解锁城市不再重复看入口视频。城市入口解锁只授予城市资格，不顺带解锁全部小关。首关免费、通关前一关免费进下一关、跳关需单关视频的规则保持原样。原来的城内整章解锁操作也仅覆盖该城市，不能解锁其他城市入口。
- 直接调用关卡页或开始关卡也会核对城市资格，不能通过已保存的免费首关资格绕过城市锁。
