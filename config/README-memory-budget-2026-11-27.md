# 内存与资源生命周期审计（2026-11-27）

本轮核对了源码中的持有/释放路径，并统计现有436关图片、UI/动画源依赖和音频。此前已有资源生命周期回归，但没有完整的真机进程、JS堆、原生和GPU峰值预算。现已按下表实施有界缓存和按使用范围释放；静态估算仍不代表真机实际内存。

可复算数据：`config/memory-audit-2026-11-27.json`。

```text
python tools/audit-memory-budget.py --output config/memory-audit-2026-11-27.json
```

图片按宽×高×4估算RGBA8、无mipmap的像素基准。构建图集、贴图压缩、CPU副本、字体字形缓存、渲染目标、引擎、脚本和宿主开销另计。音频按时长×采样率×声道×4估算全量解码float32 PCM，实际平台可能使用不同解码/流式播放方式。

## 已有清理与仍保留的内容

|资源|现行行为|建议边界|
|---|---|---|
|启动配置、关序、存档、字体、常用小图标|会话内保留；普通关卡配置按需读取后保留普通JS数据|小型全局数据常驻，避免切页反复加载|
|玩法UI、首页、章节/选关页|首次创建后隐藏复用|保留常用页面以减少反复实例化；动态卡片图片仍单独释放|
|收藏/排行节点和预设|隐藏30秒后销毁节点，下一帧归还预设引用；重新打开或在途加载会阻止/重置回收|低频大页面采用短时缓存，避免快速往返反复加载；会话内文件缓存保留|
|当前关卡上/下图|`clearLevel/onDisable`清空Sprite并decRef；加载失败/取消的迟到图也归还引用|只保留当前一组，新旧关切换短暂重叠；不缓存全章纹理|
|选关、章节、收藏动态卡片图片|翻页/关闭时释放页面引用，清空Sprite并销毁旧卡片；旧请求不能回写新页面|只保留当前可见页；磁盘下载缓存可继续保留|
|章节Bundle|最后一个页面、播放或异步任务持有者归还后removeBundle|卸载清单不等于销毁全部Asset；仍须检查图像和音频持有者|
|首页动画|26张帧图由动画依赖加载；离开10秒后先恢复所有主/子Sprite的静态帧，再归还动画资源；期间返回则取消回收|修复了只恢复主图导致子图空UV的遗漏，见`README-lobby-child-uv-fix-2026-11-27.md`；迟到或部分失败请求配对释放|
|章节惊喜道具|飞行节点结束/离开关卡销毁；跨章更换并decRef旧预设；同章预设继续复用|保留当前章即可，换章后释放旧章表现|
|章节BGM|混音器只保留当前及淡出中的曲目，淡出完成后清空音源并归还引用/包|维持有界双曲目，不强行打断淡出|
|通用BGM、通用声音|通用长音乐额外缓存最多1首，当前及淡出曲目由混音器独立持有；进入专属音乐时清空通用缓存，关闭音乐时全部归还|短音效继续保留；迟到下载不能在关闭音乐/流程销毁后重建缓存|
|三国、青花瓷专属答对音效|同章继续复用；换章或离开玩法时先停止并清空音源，再释放缓存；旧请求用版本隔离，不再重新持有引用|不与通用音效混用；旧请求失败也不能删除新一轮的在途缓存|
|后台预下载|文件与依赖预取，未实例化其他关卡或构建其玩法纹理；网页图片原始缓存对象会修剪|最多2个在途任务，临时解码/原始文件缓存仍有开销；不承诺预下载零RAM|

## 当前静态量级

|项目|RGBA8源像素基准（MiB）|说明|
|---|---:|---|
|每关两张1024×672大图|5.25|当前436关尺寸均一致|
|新旧两关大图短暂重叠|10.50|仅图片，不是整局峰值|
|一屏8张306×200缩略图|1.87|现行选关页|
|一页9张收藏图|不超过9.00|源图最大512×512；不含界面背景、详情和引擎开销|
|启动场景源图片依赖|4.70|其中Loading背景750×1625约4.65|
|玩法/结算/支持预设源图片依赖|3.05|同一图片在这组内去重|
|首页预设源图片依赖|6.90|含背景和静态首帧，不包含动态动画依赖|
|首页动画26张依赖帧图|23.92|显示时需要，离开首页10秒后释放持有引用|
|章节列表/选关/收藏UI源依赖|5.01 / 4.80 / 4.98|每组内部去重，组间共享图片不可直接相加|

15个子章节×前6关，如果把它们全部解码为大图纹理，单这些大图就约472.5MiB。因此当前按章节预下载前6关的是文件，不是把90关纹理常驻。436关全部大图像素基准约2289MiB，也不能用压缩JPG总大小替代这个量级。

音频全量float32解码假设：MainGameSources全部29个音频约61.88MiB；首页BGM约10.20MiB；青花瓷/三国的专属音效（不含BGM）分别约5.96/5.72MiB。它们是用于排查缓存上限的静态基准，不表示这些音频当前已全量解码或实际占用这些内存。
