## 画质及引用检查

- 收藏图片使用256色自适应调色板和抖动，libimagequant最低质量65、目标100；属于有损颜色量化，不宣称像素完全无损。
- 量化结果在黑/白两种底色下计算可见区域误差，仅接受PSNR不低于35dB的收藏图，当前最低35.102dB。达不到约束时保留原图或只做无损重编码，不强行降低画质。
- 原有全透明轮廓逐像素保持；原来完全不透明的像素保持不透明。半透明过渡仍保留，颜色和部分透明度会随调色板有限量化。
- 其余UI、动画等资源仅做无损优化，验证解码后的RGBA像素完全一致，避免逐帧量化影响动画。
- 所有195张图片的尺寸、文件名、路径及 `.meta` 文件字节保持不变；UUID、Texture/SpriteFrame和收藏关卡关联保持不变。
- 已抽查青花花口葡萄盘、口味虾和本次误差相对最大的剁椒鱼头，比较纹样、食物细节和透明边缘。

结果验证包括195张PNG逐张解码、文件哈希、尺寸、透明轮廓、元数据哈希及原图备份校验；青花瓷资源5项测试、40条美食图片引用、瓷器目录加载、13章325关资源路由及美食表检查均通过。
