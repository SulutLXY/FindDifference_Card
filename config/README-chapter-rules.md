# 大关卡独立配置与旧存档兼容（2026-10-21）

## 配置随主包更新

以下两份启动配置位于本地 resources Bundle，使用默认本地构建配置，不在远程 city-configs 中；修改后重新构建并更新平台代码包即可同步：

- `assets/resources/configs/cities.json`：展示顺序及完整章节元信息，由各章源清单生成，启动与存档迁移不读取远程章节包。
- `assets/resources/configs/chapter-rules.json`：旧版资格兼容规则与迁移版本。

GameFlow 分别通过 `resources.load('configs/cities')`、`resources.load('configs/chapter-rules')` 读取，无需从远端取得这两份文件。新增配置不会自动修改已发布的旧代码包，必须重新构建。

每个远程大关卡包包含本章差异点、小关缩略图和玩法大图。`assets/Bundle/levels/<city>/configs/city.json` 是章节源清单，修改后运行 `tools/build-manifest.py` 汇总到主包。大关卡封面放在独立 `chapter-covers` 包，美食图标放在独立 `food-icons` 包。完整布局和释放规则见 [README-content-bundles.md](README-content-bundles.md)。

此次目录迁移首次发布时，需要重新构建并上传所有迁移后的章节包，再更新主包。后续仅新增大关卡时，上传对应新章节包并更新主包总配置即可。只上传新章节包不会让旧主包发现新章节。为兼容未更新玩家，服务器必须保留旧版共享包及旧版仍引用的哈希文件，不能覆盖或删除旧资源。

本次调整后的验证范围见 `README-content-bundles.md`；早期阶段记录保留于 `HANDOFF-0.1.3.0-2026-10-21.md`。

## 新规则

选择页标题为「关卡选择」，卡片范围按本章显示，例如「网络热点1-30关」「宠物故事1-20关」「北京1-15关」。长文案在原设计范围内缩排，不增加按钮或卡片尺寸。

每个 `assets/Bundle/levels/<city>/configs/city.json` 独立维护：

- `levels`：本大关卡的小关清单，顺序只在本章内生效。
- `unlockMode: sequential`：小关按前一小关通关依次开放。网络热点没有前置条件，免费起步；2026热梗以 `prerequisiteCity: city-00-HotTips` 自动解锁，保留广告提前解锁。
- `unlockMode: rewarded`：首次完整观看解锁广告并成功保存后，整个大关卡的小关开放。其他大关卡通关不影响本章是否开放。当前用于宠物故事及北京至西安。

下一关和失败跳过均在本章推进，仅网络热点末关可以衔接已解锁的2026热梗。2026热梗末关、其他独立大关卡末关不跨入后续大关卡；预加载遵守相同规则。通关完当前独立大关卡可重玩本章。

继续游戏以当前/存档 `lastPlayedCityKey` 为准，选择本章首个未通关小关。成功加载对局后保存最后游玩的大关卡，重启仍继续本章。

## 两套配置与一次性升级

新配置是上述每章独立 JSON。旧兼容配置为首包的 `assets/resources/configs/chapter-rules.json`，版本为 2，保留历史 8 城市、增加热点后的 10 章节、增加宠物故事后的 11 章节顺序。旧顺序只用于首次迁移，不参与新玩家日常解锁。

- 新玩家创建存档即标记 `chapterRulesVersion: 2`，不执行旧资格恢复，不会自动得到北京等广告章资格。
- 已有 v3 存档缺少该字段时视为旧规则。先按历史顺序计算免费首章及前章全通带来的隐式资格，合并广告解锁记录和已有本章通关记录，写入新存档。
- 兼容不同历史阶段采用旧资格并集，确保以前开放的章节不重新上锁。旧玩家原有北京首章资格也保留，不需要补看广告。
- v2 数字存档先按原城市顺序转换成关卡 key，再强制执行此兼容步骤。
- 未有最后游玩章节记录时，优先继续有部分通关进度、尚未全通的旧章；再选择已开放未全通章节。保留通关星级、最佳时间、评价、积分、库存、成就及其他存档字段。
- 恢复资格、继续章节与新规则版本一次性持久化。写入失败回滚，启动提示失败并允许重试，不消耗或清空旧进度。
- 迁移完成后只使用新配置；不能删除旧兼容配置，否则尚未更新的老用户无法完成首次迁移。

后续需更新并运行 `tools/test-chapter-rules.cjs`、`tools/test-city-unlock.cjs`、`tools/test-city-renumber.cjs`、`tools/test-level-loading.cjs` 等测试，并完成实际构建与老存档验证。重新构建时需发布主包总配置和同次构建的章节包；旧构建不会自动获得这套规则。
