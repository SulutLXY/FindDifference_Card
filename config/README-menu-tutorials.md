# 主页新手引导

触发点为玩家主动返回主页（`returnToLobby`），不包括启动、资源加载失败等内部回退。

- 首次返回主页：高亮“选择关卡”；进入专题页后，高亮当前显示顺序的第二个章节入口（当前为青花瓷）。点击并成功进入该章节后完成。
- 已获得至少一件收藏后首次返回主页：高亮“收藏册”；进入后高亮“全部”第一页的第一件已获得收藏，打开详情后完成。沿用收藏列表的新获得、已获得、ID 排序，不会引导未获得物品或请求激励解锁。
- 同次回主页同时满足两项条件时，专题引导优先，收藏引导保留到下次回主页。不自动将玩家从专题页切回主页。

复用现有 `GameTips` 遮罩与“跳过引导”，每条引导独立保存 `entry` / `target` / `done` 到原存档 `menuTutorials`。完成或跳过后不再出现；途中退出或返回主页会从入口继续，不改动局内新手引导完成标记、关卡进度、收藏及奖励。

插屏加载或展示、激励视频、页面加载及其他弹窗期间等待；自动签到暂缓到引导处理后。引导点击沿用正常页面入口，广告与章节资格逻辑继续生效。收藏高亮等待实际图片加载成功。

旧存档没有这两个新标记时，更新后的首次主动回主页也会触发；清除存档会重置引导。

2026-11-25 补强收藏资格检查：拥有实际藏品、获得后主动返回主页，两项条件同时满足后才可播放收藏引导。启动或领取当帧不会直接开始；旧存档即使已有 collection 的 entry/target，也需满足条件后回到主页才能继续。展示、持续高亮及点击跳转都会复核持有藏品的条件，无资格的旧进度不会阻挡自动签到。已完成或跳过的引导保持原完成记录。

验证：

```powershell
node tools/test-menu-tutorial.cjs
node tools/test-collection.cjs
```

真机验收：新存档完成或退出首关后返回主页，关闭插屏，点击高亮的选择关卡和第二专题；获得收藏后回主页，点击收藏册并打开高亮藏品。重进游戏后已完成的对应引导应保持不再出现。另测中途退出、跳过、慢速资源加载以及签到可领取时的弹窗顺序。
