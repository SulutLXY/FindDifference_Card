# 0.1.0.0 修改记录

本次发布拆分首包、局内素材和城市关卡资源，并调整启动、加载失败回退及广告规则。

## 资源与目录

- 首包保留首页所需资源和城市总索引 `assets/resources/configs/cities.json`，main 不使用远程包。
- 局内素材移入 `assets/PleyGame`，Bundle 为 `MainGameSources`。GameScreen 和 ResultModal 改为独立预制体，首次进关时加载并创建。
- `assets/Bundle` 及其 `levels` 仅作为组织目录。`configs` 为 `city-configs` Bundle，`thumbnails` 为 `city-thumbnails` Bundle。
- `levels` 下 8 个城市目录分别启用 Bundle，名称对应城市目录，例如 `city-01-beijing`。大图加载及跨城市预加载按目标城市选包。
- 城市配置改为 `configs/city-01-beijing.json`，城市图标改为 `configs/city-01-beijing-icon.jpg`。小关卡配置放入 `configs/城市/关卡/differences.json`；选关封面及美食图标放入 thumbnails；大图留在 levels。
- 同步城市、选关、美食图鉴、音频和配置生成器的加载路径，更新美食维护表中的资产路径。移除主场景模板对远程图片的直接引用。
- 移动资源保留原 UUID，城市/关卡存档标识保持一致。保留玩家此次替换的关卡图片及差异点 ID、坐标、半径和数量，仅修正误填的名称、类型及美食字段。

## 玩法与加载

- 启动后直接进入存档对应关卡；新玩家进入第一关。
- 启动、手动选关或配置加载失败时返回首页。结算点击下一关失败时，只尝试一次再下一关，支持跨城市；再次失败或没有后继关卡时返回首页。
- 每次进关只读取目标关卡配置，失败或跳过不会标记通关、发放奖励或消耗当天首关免插屏资格。
- 删除 level-00 敬请期待占位卡，旧占位目录不进入正式关卡清单。

## 广告与版本

- 修复城市解锁按钮因游戏暂停状态而未请求抖音激励广告的问题，增加重复请求保护。
- 删除前三关免插屏限制，统一为玩家当天首个成功进入的对局免插屏。同一天重启不重置保护，后续开局按现有广告条件触发。
- 应用版本提升至 `0.1.0.0`，资源版本为 `0.1.0`；同步项目版本、FooterEnv 显示和抖音启动模板。

## 验证与发布

已通过类型检查及城市资源路径、关卡加载回退、局内包加载、城市解锁、辅助道具、连击、美食关联、H5 广告行为和版本迁移相关测试。

按照玩家要求保留新差异点数据：旧校验器仍会报告 21 个半径超过 0.2、1 个 y 坐标为负数。这些不是本次目录迁移新增的问题，未自动缩小或移动点位。

尚未完成 Cocos 全量构建和抖音实机广告验证。发布时需重新构建，并部署同次构建产生的 MainGameSources、city-configs、city-thumbnails 和各城市远程包。构建产物及临时文件不纳入版本库。

目录与加载规则见 `README-game-bundle.md`；版本与缓存规则见 `README-app-version.md`。
