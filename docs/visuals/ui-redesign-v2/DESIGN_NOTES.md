# UI 重设计 V2

## 设计方向

- 找茬插画：继续使用现有皇家幻想卡通风格。
- 界面风格：薄荷绿、奶油白、柔和黄色和少量珊瑚色点缀。
- 材质：软质 3D、圆角胶囊、低对比描边、轻微浮雕和柔和投影。
- 原则：找茬图片是核心，UI 不使用大面积深蓝或厚重金属边框抢占视觉。
- 参考图只用于提取色彩、圆润程度和轻松氛围，不复用其中的庄园、角色、图标或版式。

## 页面

1. `01-home-v1.png`：主页
   - 顶部资源条
   - 游戏临时标题
   - 皇家城堡微缩景观
   - 开始按钮和继续关卡卡片
   - 四项底部导航

2. `02-gameplay-v1.png`：核心游戏页
   - 返回、关卡、生命和倒计时
   - 八个差异进度点
   - 上下两张皇家城堡庭院图片
   - 提示、加时、分享和声音入口

3. `03-leaderboard-v1.png`：排行榜
   - 好友／全服切换
   - 前三名领奖台
   - 排名列表
   - 我的排名固定卡片
   - 底部导航

4. `04-level-select-v1.png`：关卡选择
   - 五关微缩地图
   - 已解锁与锁定状态
   - 当前关卡详情卡片
   - 底部导航

## 建议基础色

- 主薄荷：`#66CDB6`
- 深薄荷：`#389E8C`
- 浅薄荷背景：`#DDF6EB`
- 奶油白：`#FFF6DF`
- 暖黄色：`#F7C957`
- 珊瑚红：`#F27D68`
- 主文字：`#4E6B5F`
- 次级文字：`#8A796C`

## 确认后需要单独制作的可用素材

- 全屏浅色背景及可平铺纹理
- 顶部标题胶囊、资源胶囊、返回按钮
- 通用奶油面板与薄荷面板九宫格
- 主按钮、次按钮、锁定按钮的正常／按下／禁用状态
- 底部导航底板、选中气泡和四个导航图标
- 星星、金币、提示券、爱心、时钟、放大镜、沙漏、分享、声音图标
- 八个进度点的未完成／已完成状态
- 关卡节点、星级槽、锁头和关卡详情卡片
- 排行榜前三名底座、皇冠、普通排名行和我的排名卡片
- 结算弹窗面板、星级与胜败装饰（沿用同一套 V2 语言）

这些素材应以透明 PNG 和可拉伸九宫格为主，按当前 Cocos 场景节点尺寸导出，而不是直接裁剪整张效果图。
