# UI V3：轻量 H5 版式

## 核心原则

- 设计基准：750 × 1334。
- 找茬图片继续使用皇家幻想卡通风格，UI 不改变关卡插画风格。
- 页面版式参考用户提供的主页、排行榜和网格列表结构，但不复用其中的角色、Logo、照片、图标或具体美术。
- UI 以规则圆角矩形、胶囊和圆形状态点为主，避免复杂轮廓。
- 面板必须保留大面积纯净中心区域，方便制作 Cocos 九宫格。
- 同类内容复用同一张九宫格，不为每个按钮、排行行或关卡卡片制作独立背景。
- 面板背景色 HSL 饱和度不超过 50%。关卡缩略图属于内容图片，不受此限制。

## 页面版式

### 主页

- 上部：设置入口和游戏标题。
- 中部：皇家庭院主题展示。
- 下部：一个主按钮、左右两个快捷入口、一个每日挑战按钮。
- 不使用资源条和底部 Tab 栏。

### 核心游戏页

- 顶部仅保留返回、关卡、生命、时间和八个进度点。
- 两张找茬图占据页面主要面积。
- 底部仅保留提示、加时和分享。
- 图片框只使用一张低饱和浅色九宫格。

### 排行榜

- 好友／全服使用一个二段式胶囊。
- 1–10 名全部复用相同排行行背景。
- 前三名仅替换左侧排名色块，不使用大型领奖台。
- “我的排名”复用排行行结构，只增加浅黄色状态色。

### 关卡选择

- 使用双列滚动网格，不使用复杂地图。
- 五个正式关卡和一个占位卡复用同一张卡片背景。
- 解锁、锁定、选中状态通过角标、锁图标和描边控制。

## 面板颜色

以下颜色均可直接作为 UI 面板底色，其 HSL 饱和度不超过 50%。

| 用途 | CSS HSL | 参考 HEX |
|---|---:|---:|
| 奶油白面板 | `hsl(45 25% 93%)` | `#F1EFE9` |
| 浅蓝灰面板 | `hsl(215 28% 84%)` | `#C9D3E0` |
| 灰蓝状态块 | `hsl(215 20% 72%)` | `#A9B5C6` |
| 淡鼠尾草绿 | `hsl(120 18% 76%)` | `#B8CDB8` |
| 暖灰黄色选中态 | `hsl(42 40% 78%)` | `#DDCFAE` |
| 深灰蓝文字 | `hsl(220 20% 32%)` | `#41485F` |

小面积星星、爱心、主要按钮可以使用更鲜明的强调色，但不能作为大面积面板底色。
