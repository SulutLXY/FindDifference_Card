# 0.0.6.0 更新说明

日期：2026-10-10。此提交包含本轮玩法逻辑调整，以及工作区内配套的场景、动画、关卡图片、差异坐标和编辑器配置更新。

## 玩法与界面

- 选城页未解锁城市显示 BtnUnlock，激励视频完成后提前解锁并保存；已解锁城市显示 ProgressPoint，两者互斥。
- 找茬生命值使用关卡名下方的 LivesItem 爱心显示，按剩余生命数更新，隐藏旧生命数字。
- 普通连击判断窗口为 5 秒，最高连击要求 3.5 秒内续接。第 5 次及之后满足条件时随机显示 ComboTips 图片和一次随机动画，固定位置、随机旋转 -10° 至 10°，1 秒后关闭。
- 普通成功文字与大连击提示互斥；普通文字靠近点击找到的差异圈，随机旋转 -15° 至 15°、字号 28/32/36、六种指定颜色，并使用白色 2 像素描边。
- 第一次成功随机文字：Good、不错！、答对了！；第二次：有一手~、Great、漂亮！、好眼力~；第三、四次：夯爆了、这波很顶、牛来！、狠狠拿捏、直接拉满！、绝绝子~。
- 提示改为可穿透的临时遮罩，2 秒自动消失，下一次点击也会关闭；不暂停计时、不代替玩家确认差异，点击其他位置继续正常判定。输入监听绑定到具有 UITransform 的祖先，修复 cameraPriority 空引用问题。
- 美食详情点击框外关闭，TimeOver 显示 8 秒关闭倒计时；评论输入期间暂停，结束后继续剩余倒计时。
- 隐藏辅助引导多余的“知道了”文字；预览引导开关只控制编辑器强制演示，正式版本仍按新玩家存档自动触发教学。
- 加载页隐藏“返回首页”文字，猫的位置跟随进度条填充末端移动，保留失败重试入口。
- 首页继续关卡标签只显示关卡名，隐藏城市前缀，使用单行缩放显示。

## H5 无广告版本

- Web 构建按 H5 平台处理，即使网页处于有小游戏 SDK 的环境中也不误判为小游戏平台。
- H5 激励视频直接返回奖励成功，插屏广告跳过。
- H5 关卡内提示、加时无限使用，不消耗库存或增加广告使用次数；对应按钮隐藏次数和广告标识。
- 微信、抖音小游戏继续使用原有广告与道具次数规则。

## 资源与美食配置

- 项目 PNG 执行最多 256 色压缩，保留透明度；JPG 执行 quality 80 压缩，作为 PS 8 品质的近似处理。压缩工具和可恢复的原图备份流程一并维护，备份位于被忽略的 temp 目录。
- 成都“制作夫妻肺片”的 scene-b、icon 和广州“制作白切鸡”的备用 scene-c 补齐 SpriteFrame 导入配置，保持原资源 UUID。
- 检查 8 个城市、120 个正式关卡、411 张城市关卡图片和 40 个美食图标，资源解码、SpriteFrame、尺寸和引用均通过。
- 成都、西安 10 道美食补齐获得关卡；长沙 4 道、广州肠粉/叉烧校正关联顺序。广州第 03 关图片为白切鸡，纠正误填的“艇仔粥”名称。
- 全部 40 道美食使用原设计的美食素材；获得美食和收藏详情不再回退显示关卡 ICON。源配置表和导出的 JSON 同步更新。
- 配置导出校验在 food 字段为空时使用关卡名称，兼容项目已有的美食别名，防止关卡调整后继续发放错误美食。
- 同步应用版本、运行时代码、抖音构建模板版本至 0.0.6.0；保留现有远端地址配置。
- 纳入工作区已有的关卡差异坐标、美术替换、场景组件摆放、连击动画/图标和 particle-2d 引擎模块配置。
